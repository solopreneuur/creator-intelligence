# Audience problems

An optional lens for bridges, not a filing system. Cards are never filed by
audience problem, so the audience can change without breaking anything.

Empty for now. Until it has content, each bridge picks the audience problem
itself. When you add problems, bridges will aim at these first, with one
off-list option allowed.

Format: `- <problem in the audience's own words> · <one line on who has it>`
