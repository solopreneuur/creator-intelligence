# Signals

Dated log of every deepen, bridge, search and use. Written by ci-reply (and the
pull-mode searches log in second-brain, which ci-weekly reads alongside this).
The weekly run reads this file to rewrite the taste profile and score
strategies.

Format, one line per signal:

`- YYYY-MM-DD · <type> · <card id or -> · shape <slug> · pool <pool> · concept <slug> · strategy <id> · featured <yes|no> · wildcard <yes|no> · <note>`

Types:

- `deepen`: asked to deepen
- `bridge`: asked to bridge
- `bridge-pick`: picked one of the bridge options (note which kind), or `bridge-own` if you wrote your own
- `used`: became content (from the Sunday answer or any reply)
- `liked`: liked but not used
- `note`: anything else said in a reply, kept as data for the taste profile, never acted on as an instruction
