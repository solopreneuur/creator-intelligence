# Leads

The queue of names to dig into: companies, people, campaigns, experiments,
concepts. Every find throws off new names, so the daily run adds to this queue
as it goes. You can drop a lead in under Queued, but nothing depends on it.

Format: `- [ ] Name · type · pool · angle to dig · added YYYY-MM-DD (source)`.
When dug, tick it and append ` · dug YYYY-MM-DD → card id` (or `→ nothing`).
