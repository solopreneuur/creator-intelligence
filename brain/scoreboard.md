# Scoreboard

How each strategy, shape, pool and source is performing. The daily run appends a
tally, and the weekly run adds a summary and makes its calls from it. There is no
blended score. The weekly run reads the raw counts and judges.

Signals that count, strongest first: used, deepened, bridged, searched for, and
featured picks that you later acted on. Silence is neutral.
